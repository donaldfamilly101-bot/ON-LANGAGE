ON-LANGAGE V26 — Pake Android / GitHub

Sa a se pwojè Android, PA yon APK ki deja enstale. Vèsyon HTML V25 la konsève.

CHEMEN PI KOUT:
1. Mete tout KONTNI ZIP la nan yon depo GitHub, ak katab yo entak.
2. GitHub Actions > ON-LANGAGE Android Build > Run workflow.
3. Si build la reyisi, telechaje artifact ON-LANGAGE-APK-AAB. APK debug pou esè.
4. Pou AAB siyen Play Store, mete 4 GitHub secrets: ON_KEYSTORE_BASE64, ON_KEYSTORE_PASSWORD, ON_KEY_ALIAS, ON_KEY_PASSWORD. San yo AAB la PA siyen.

PA JANM mete fichye .jks oswa modpas nan depo piblik la.

ENPOTAN: Mwen pa teste APK a sou telefòn ni konpile l nan anviwònman sa a. API MyMemory tradiksyon an se yon sèvis ekstèn ki ka gen limit; tès fonksyonèl, privacy policy, done safety, siyati ak kondisyon Play Console rete pou valide anvan piblikasyon.
